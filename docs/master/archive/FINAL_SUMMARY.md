## 🚀 How to Use

### For Beginners

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Read the Quick Start
# See QUICK_START.md

# 3. Try with small dataset
python smart_dedup.py ~/test_folder --dry-run
```

### For Power Users

```bash
# Use Rust for maximum performance
.\exe\delete_duplicates.exe ~/large_folder --batch --keep newest
.\exe\organize_files.exe --source ~/Downloads --mode type --move
.\exe\rename_files.exe --extension jpg --prefix photo_ --padding 4
```

### For Automation

```bash
# Daily cleanup script
.\exe\delete_duplicates.exe ~/Downloads --batch --min-size 1024
.\exe\organize_files.exe --source ~/Downloads --mode type --move
.\exe\clean_empty_dirs.exe --directory ~/Downloads
```
